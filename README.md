## What is submitted in each folder

Every case study folder contains:

- `README.md` — problem statement, objectives, assumptions, algorithm, flowchart, pseudocode, source code, test cases, output screenshot and conclusion
- `flowchart.png` — flowchart image of the program
- `solution.py` — the Python program
- `test_cases.py` — test cases written to check the program
- `output.txt` — output of the program
- `output_screenshot.png` — screenshot of the output
- `demo_input.txt` — sample input (only for the two menu-based programs, case 7 and 10)

**Combined PDF:** all 10 case studies are also compiled into a single document (every required section — problem statement, objectives, assumptions, algorithm, flowchart, pseudocode, source code, test cases, output screenshot and conclusion):
